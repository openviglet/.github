![The Viglet suite: Dumont, Turing and Shio](https://raw.githubusercontent.com/openviglet/.github/main/images/viglet-banner.png)

Open source enterprise search with generative AI, the platform that feeds it, and an
agent-ready CMS: self-hosted, Apache 2.0, built to work together or each on its own.

| | |
|---|---|
| **[Viglet Turing](https://github.com/openviglet/turing)** · Enterprise Search | Faceted semantic search, RAG chat with citations and AI agents over your own content; an open source alternative to Algolia and Coveo |
| **[Viglet Dumont](https://github.com/openviglet/dumont)** · Data Exchange Platform | Connects AEM, WordPress, databases, files and web sites, and delivers their content to Turing, Solr or Elasticsearch |
| **[Viglet Shio](https://github.com/openviglet/shio)** · Agent-ready CMS | A CMS that people run from the console and AI agents run over MCP; renders pages or delivers them over REST and GraphQL |
